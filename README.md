# عالم المستكشفين الصغار — Little Explorers World

تطبيق تعليمي عربي/إنجليزي تفاعلي للأطفال من **3 إلى 5 سنوات**، مبني بـ **Flutter/Dart**، يعمل بالكامل دون إنترنت، دون حسابات، دون إعلانات، ودون جمع أي بيانات.

> «الطفل يظن أنه يلعب مغامرة… وهو يتعلم الحروف والأرقام والألوان.»

---

## 1) نظرة سريعة

| البند | القيمة |
|---|---|
| المنصة | Android (Flutter 3.16+ / Dart 3) |
| اللغتان | العربية (RTL كامل) + الإنجليزية |
| الاتصال | لا يطلب إذن الإنترنت إطلاقًا — كل المحتوى محلي |
| البيانات | تُحفظ محليًا على الجهاز فقط (SharedPreferences / JSON) |
| الإعلانات/الشراء | لا يوجد |
| الحد الأدنى | Android 5.0 (API 21) |

**العوالم الخمسة:** جزيرة الحروف (28 حرفًا عربيًا) • حديقة الأرقام (0–10) • مدينة الحروف الإنجليزية (A–Z) • غابة الألوان والأشكال (10 ألوان + 8 أشكال) • قلعة الأبطال (الملصقات والكنوز).

**الشخصيات الأربع:** لولو الأسد، توتو الأرنب، بوبو الروبوت، فوفو الفراشة — كل واحدة بثلاثة أوضاع (ترحيب/إشارة/احتفال) وتظهر كموجّهة تفاعلية في الدروس والألعاب.

**12 لعبة منفذة فعليًا:** استمع واختر • اسحب الحرف إلى الصورة • طابق الكبير بالصغير • بطاقات الذاكرة • إطعام توتو جزرةً جزرة • فقّع البالونات بالعدّ • فقاعات الحروف الطافية • اجمع النجوم • قطار الأرقام • اختر المختلف • ابحث عن الحرف المختبئ • أكمل النمط.

**نظام التعلم:** مراحل متسلسلة تُفتح تدريجيًا • نجوم 1–3 حسب الأخطاء (بلا مؤقتات ولا ضغط) • مراجعة تلقائية لما أخطأ فيه الطفل مع فوفو • صندوق كنز كل 15 نجمة • 12 ملصقًا تُفتح بالنجوم • تلميحات تلقائية بعد محاولتين • احتفال بعد كل مرحلة • عوالم تُفتح بعتبات نجوم (ويستطيع ولي الأمر فتحها كلها).

## 2) التشغيل وبناء APK

```bash
cd little_explorers
flutter pub get

# توليد مجلدات المنصة (مرة واحدة) — المستودع لا يتضمن android/ عمدًا
flutter create --platforms=android --org com.littleexplorers .

flutter run                 # تجربة على جهاز/محاكي
flutter build apk --release # بناء APK للتوزيع
# الناتج: build/app/outputs/flutter-apk/app-release.apk
```

- **لماذا لا يوجد مجلد android/؟** حتى يحصل كل مُستخدم على قوالب محدّثة متوافقة مع نسخته من Flutter؛ أمر `flutter create .` لا يمس الكود أو الأصول.
- **الأيقونة:** الأصل في `assets/icon.png`، وبعد `flutter create` شغّل `python3 tools/make_icons.py` لتوليد أحجام mipmap.
- **معرّف التطبيق:** يُضبط في `android/app/build.gradle` بعد التوليد (افتراضي `com.littleexplorers.little_explorers`).
- **الاتجاه:** مقفول على العمودي عمدًا (مناسب للأطفال) — يُدار من `main.dart`.

## 3) بنية المشروع

```
lib/
├── main.dart / app.dart        # التمهيد، المزودات، RTL، حفظ التقدم عند الخروج
├── core/                       # الألوان، سجل الأصول، الثيم، القياسات المتجاوبة
├── l10n/app_strings.dart       # كل النصوص عربي/إنجليزي في مكان واحد
├── data/
│   ├── models.dart             # UnitDef / SubjectDef / WorldDef / GameType
│   ├── content_*.dart          # ★ محتوى الحروف والأرقام والألوان (عدّل هنا)
│   └── worlds.dart             # ★ العوالم والملصقات وحدود الفتح (عدّل هنا)
├── services/                   # الإعدادات، التقدم المحلي، الصوت، نطق الجهاز
├── game_engine/                # مضيف الألعاب + شريط التعليمات + أدوات مشتركة
├── games/                      # ★ 12 لعبة مستقلة قابلة لإعادة الاستخدام
├── widgets/                    # الحرف المجسّم، الشخصيات، الاحتفال، الأشكال
└── screens/                    # الترحيب، الخريطة، المركز، الدرس، القلعة، الوالد
```

**قرارات معمارية:** فصل كامل بين المحتوى (data) والمنطق (games/engine) والواجهة (screens/widgets) والخدمات (services)؛ إضافة عالم أو لعبة أو حرف لا تتطلب لمس أي كود آخر — راجع `docs/CONTENT_GUIDE.md`.

## 4) الصوت — وكيف يعمل دون إنترنت

| النوع | المصدر | دون إنترنت |
|---|---|---|
| 9 مؤثرات صوتية (لمس/فرح/فقع/كنز…) | مولّدة ومضمّنة `assets/audio/sfx/*.wav` | دائمًا |
| موسيقى خلفية هادئة (لوب 26 ثانية) | مضمّنة `assets/audio/music/peaceful_loop.ogg` | دائمًا |
| تعليق **إنجليزي**: 26 حرفًا + 26 كلمة + 11 رقمًا + 14 تعليمة | تسجيلات مولّدة مضمّنة `assets/audio/en/*.ogg` (~0.8MB) | دائمًا |
| تعليق **عربي** (أسماء الحروف والكلمات والتعليمات) | محرك نطق الجهاز `flutter_tts` (Google TTS يوفر صوتًا عربيًا فصيحًا يعمل دون إنترنت على معظم أجهزة Android) | على معظم الأجهزة* |

\* إن لم تتوفر حزمة الصوت العربي على الجهاز يتراجع التطبيق رشيقًا (رموز بصرية + مؤثرات دون توقف). للتفعيل: إعدادات الجهاز ← النطق ← تنزيل «العربية». وإن فُقد أي ملف صوتي إنجليزي مستقبلًا يتراجع تلقائيًا لنطق الجهاز.

**الخصوصية:** التطبيق بلا إذن إنترنت أساسًا في نسخة الإصدار، فلا يمكن إرسال أي بيانات ولو أراد.

## 6) قائمة صادقة: ما نُفّذ وما لم يُنفّذ

### نُفّذ بالكامل ✓
- بنية قابلة للتوسع + 12 لعبة حقيقية بتحقق إجابات وتغذية راجعة وتكيّف تلميحات.
- تدفق درس كامل: تقديم تفاعلي ← كلمة/عدّ ← لعبة ← احتفال ومكافآت.
- حفظ/استعادة التقدم محليًا + حفظ عند الخروج للخلفية + إعادة ضبط بتأكيد مزدوج.
- RTL كامل وتبديل لغة فوري دون اختلاط اتجاهات؛ خط طفولي مضمّن (Baloo Bhaijaan 2).
- بوابة والد (عملية ضرب) + لوحة تقدم ومهارات ومراجعة وإعدادات كاملة.
- أصول مولّدة ومُعالجة: 12 شخصية بثلاثة أوضاع (قص خلفية آلي بـ GrabCut)، 6 خلفيات عوالم، 43 صورة كائن، أيقونة، 9 مؤثرات، موسيقى، 77 تسجيلًا إنجليزيًا.
- تجاوب شاشات (هواتف وأجهزة لوحية) عبر نظام قياس موحّد، مع خيار «تقليل الحركة».

### لم يُنفّذ / قيود (بشفافية كاملة)
1. **لم يُبنَ APK ولا اختُبر على جهاز** — بيئة التطوير لا تضم Flutter/Android SDK. الأوامر أعلاه جاهزة؛ أول تشغيل لديك يكشف أي خطأ بناء محتمل (الكود مكتوب وفق APIs مستقرة شائعة الاستخدام: provider 6 / audioplayers 6 / flutter_tts 4 / shared_preferences 2).
2. **التعليق العربي** بصوت الجهاز وليس تسجيلات بشرية (القسم 4).
3. **المظهر «ثلاثي الأبعاد»** محقق بعمق مصطنع: طبقات استخلاص، تدرجات، ظلال، إضاءة لمعان، حركة ارتداب — نص متجهي حاد لا نماذج GLB؛ قرار أداء مقصود ومصرّح به في المواصفة.
4. **أشكال الحروف حسب الموقع** تُعرض كشريط تعليمي (بـ Tatweel) دون تمارين مخصصة عليها — تحسين مستقبلي.
5. بعض قصّات الصور قد تحتاج تدقيقًا بشريًا: أي صورة لا تُعجبك استبدلها بنفس الاسم في `assets/images/…` (قائمة فحص في `docs/ASSET_STATUS.md`).
6. لا توجد نماذج GLB حقيقية ولا مشهد محرك ثلاثي الأبعاد — كما وثّق أعلاه.
